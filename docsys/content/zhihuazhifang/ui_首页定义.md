# 首页定义（项目库）

> 类型：**全局定义**——定义完整目标产品的首页，超前于当前实现；某项能力是否已落地不影响定义成立（实现状态只在 §7 实现映射登记）。
> 观感与文案规则见《UI 设计规范》，颜色字号取值见《设计令牌与主题扩展规范》，改动波次见《交互优化升级方案》（U0.5）。

## 1. 定位

首页即**项目库**，是创作者进入 TalkScene 的第一屏。它只回答三个问题：

1. 我有哪些作品？
2. 每个作品进行到哪一步？
3. 我现在能干什么？（继续制作 / 新建 / 导入 / 导出）

非目标（首页不承载）：生产操作（进工作室完成）、运维监控（守护台职责）、教学长文（进帮助/docsys）。

## 3. 区域定义

### 3.1 顶栏
| 元素 | 内容 | 行为 |
|---|---|---|
| 品牌位 | 产品名「talkscene · 工作台」 | 点击回首页 |
| 主导航 | 脚本 → 蓝图 → 合成 → 导出 四工作室入口 | 跳转当前选中项目的对应工作室；无选中项目时指向最近打开项目 |
| 任务指示器 | 进行中的长任务（批量出图/导出/视频合成）计数徽标 | 点击展开任务清单（进度+可取消）；无进行中任务时隐藏 |
| 守护台入口 | 图标按钮 | 新开守护台控制台（治理/审核界面，面向负责人与二次开发） |
| 设置入口 | 图标按钮 | 打开设置页（独立页面，见《设置定义》） |

### 3.2 创建卡
新建互动故事的第一入口。点击进入**新建页**（独立页面）：主体是一句话创意输入；结构公式、模板等高级选项折叠。卡片文案一句话说明产物（"一句话创意，AI 生成可交互故事"）。

### 3.3 导入入口
与创建卡并列的次级入口。接受两类来源：导出包（.zip）与项目目录；导入前校验清单（schema 版本/必填文件/资产完整性），校验失败给原因不静默；导入成功即入项目库，状态按真相源实算。

### 3.4 草稿条目
AI 生成中途放弃或待确认的故事收进草稿。定义行为：草稿**是列表内一行条目**（可展开为草稿列表），不是与项目卡并列的大卡；空态显示一行"暂无草稿"，不占黄金位。草稿两动作：载入继续生成（覆盖重出）、打开项目（确认毕业进项目列表）。

### 3.5 列表工具条
固定于列表上方一行：左侧搜索框（按标题匹配），右侧排序（按更新时间/按名称）、状态筛选（全部/制作中/已完成/已导出）与**视图切换（画廊/简洁，选择记忆在本地）**。样式取组件令牌。

### 3.6 项目卡
项目卡是项目库的最小单元，分两种形态（视图切换选择）：

**画廊卡**（默认）：封面比例跟随 `stage.orientation`——竖屏故事竖卡（aspect = stage.width/height）、横屏故事横卡，缺尺寸按 3/4；封面左上状态徽章、右上"⋯"菜单、底部四段进度、悬停浮出主操作。

**简洁卡**：无封面；标题 + 状态徽章 + 四段进度 + 相对时间 + ⋯菜单，信息密度近似旧版列表卡。

| 部位 | 定义 |
|---|---|
| 信息序 | 标题 → 状态行（用户语言）→ 相对时间；三行位置逐卡一致，缺内容显示占位不撤行 |
| 进度表达 | 由状态徽章承载（徽章即进度结论）；不另设分段进度条（2026-10-20 负责人裁决：蓝条语义不清，已移除） |
| 主操作 | 整卡点击 = **继续制作**（按 §4 状态路由到对应工作室） |
| 角标菜单 | 卡片右上角"⋯"菜单：导出 H5 / 导出视频 / 重命名 / 复制副本 / 删除 |
| 删除 | 二次确认，文案与对象一致（删项目即说"删除项目"） |
| 封面来源 | 优先级：专用封面资产（名称/路径含「封面」或 cover，不区分大小写）> 首个可解析场景背景图 > 色卡封面（标题哈希渐变 + 首字徽标） |

**封面图资产（定义先行）**：创作链后续在合成阶段提供封面图生成（专用资产，命名含「封面」入库即被首页识别）；当前以首场景图为代理，生成链未动。

### 3.7 右栏
| 分区 | 定义 |
|---|---|
| 说明区 | 三段以内用户语言：这是什么工具、第一步做什么、去哪看帮助 |
| 环境状态 | 技术语言寄存器，默认折叠；展开后成行成组（文本模型 / 图像服务 / 审核模型 / 语音 / 视频，格式 `provider / model`） |
| 最近动态 | 最近项目事件（可玩/待导出等），点击直达对应项目 |

## 4. 项目卡状态定义（逻辑图）

状态以服务端真相源（项目阶段 + 出图总账）计算，经"内部状态 → 用户语言"映射表单一来源输出：

| 内部判定 | 用户语言 |
|---|---|
| 生成中途放弃/待确认 | 草稿 |
| 有脚本，场景图未齐 | 制作中 · 还差场景图 |
| 图文完整，未导出 | 已完成 · 可导出 |
| 已导出可玩 H5 | 已导出 · H5 |
| 已导出预演视频 | 已导出 · 视频 |
| 两种产物均已导出 | 已导出 · H5+视频 |

```chart flow
create: 新建
draft: 草稿
making: 制作中
done: 已完成
exported: 已导出
create -> draft: 中途放弃
create -> making: 生成确认
draft -> making: 载入继续生成
making -> done: 图文完整
done -> exported: 导出 H5 或视频
done -> making: 再编辑回退
```

## 5. 交互逻辑（逻辑图）

```chart flow
open: 打开首页
grid: 项目网格
card: 点项目卡
studio: 对应工作室
new: 点创建卡
imp: 点导入入口
gen: 新建页·一句话生成
check: 导入校验
open -> grid
grid -> card: 继续制作
card -> studio: 按状态路由
grid -> new
grid -> imp
new -> gen: 生成后进蓝图审阅
imp -> check: 过检入库
```

路由规则：草稿/制作中 → 最早未完成阶段的工作室；已完成 → 合成；已导出 → 合成（预览态）。

## 6. 数据流（分层图）

```chart layers
界面层 首页组件（项目卡/工具条/右栏/任务指示器）
API 层 GET /api/projects · 出图总账 coverage · 项目阶段 · 长任务列表
真相源 storage/projects/<id>/ project.json + plan.json
```

首页只读不写真相源；一切状态由服务端计算供给，前端不自行推断（与"唯一事实流"原则同源）。

## 7. 代码结构（真相文件树，以仓内文件为准）

```text
apps/editor/src/
  pages/HubPage.tsx          # 首页路由：装配顶栏/主区/右栏
  hub/TopBar.tsx             # 品牌位 · 主导航 · 任务指示器 · 守护台/设置入口
  hub/CreateEntryCard.tsx    # 新建互动故事入口卡
  hub/ImportEntry.tsx        # 导入项目入口（导出包/目录 + 校验）
  hub/DraftEntry.tsx         # 草稿条目（空态一行，可展开）
  hub/ListToolbar.tsx        # 搜索 / 排序 / 筛选工具条
  hub/ProjectGrid.tsx        # 项目网格（流式栅格）
  hub/ProjectCard.tsx        # 项目卡：标题→状态行→相对时间 + 角标菜单
  hub/SideRail.tsx           # 右栏：说明 / 环境状态(折叠) / 最近动态
  hub/projectStatus.ts       # 内部状态→用户语言映射表（单一来源）
  api.ts                     # 与业务后端通信（既有，复用）
server 侧（只读供给）
  routes/studio.routes.js    # 项目列表 / 健康检查
  routes/storyScenes.routes.js  # 出图总账 coverage 供给
storage/projects/<id>/       # 真相源：project.json + plan.json
```

实现映射：当前实现为 `apps/editor/src/studios/Hub.tsx` 单文件（1,929 行，创建弹窗+草稿箱+项目卡+设置入口内联），按《模块化拆分设计》§6.3 裁决随 U0.5 波迁移为上树；任务指示器、导入入口、守护台入口、视频导出态为定义先行项，随对应能力波次落地。

> 注记：画廊版首页已实施（2026-10-20：封面/状态徽章/系统状态抽屉/搜索筛选/新建英雄卡，`apps/editor/src/hub/` 辅助模块 projectStatus/relativeTime/coverColor；`/api/projects/summary` 供给 `cover` 字段）。
> 注记（2026-10-20 第二波）：卡片朝向跟随 `stage.orientation`（summary 供给 `stageConfig`）、画廊/简洁双视图切换（localStorage 记忆）、封面来源优先级（专用封面资产 > 首场景图 > 色卡封面）已实施。

## 8. 自适应行为

| 断点 | 布局 |
|---|---|
| ≥1440 | 三栏：顶栏 / 主区（卡片 3–4 列流式）/ 右栏 320 |
| 1024–1440 | 两栏：右栏折叠为抽屉，卡片 2–3 列 |
| <1024 | 单栏：右栏与导航抽屉化，卡片 1–2 列 |

1280 以下允许横向滚动，不允许布局破碎。

## 9. 文案与令牌应用

- 卡片状态行、按钮、空态全部出自状态映射表与语言包 key，禁写死文案（《UI 设计规范》§3、《设计令牌与主题扩展规范》§7）。
- 全部颜色/字号/间距/圆角取 `--ts-*` 语义令牌；首页是三档断点截图基线的首批入库页面。
