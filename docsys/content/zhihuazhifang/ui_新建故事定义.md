# 新建故事定义（一句话创作入口）

> 类型：**全局定义**——定义完整目标产品的新建故事界面，超前于实现状态。观感与折叠/图标/分割线规则见《UI 设计规范》，主流程页内化依据其 §7（禁止全屏表单弹窗承载主流程）。

## 1. 定位

新建故事是**创作入口页**，回答一个问题：你想讲一个什么故事？用户主体动作只有一句：写一句话创意，点生成。产物是脚本层草稿项目（先进草稿箱待确认，打开即毕业进项目库）。

非目标：不承载脚本精修（进脚本工作室）、不做结构编辑（进蓝图工作室）。

## 3. 区域定义

### 3.1 页首
返回按钮（回来源界面，默认项目库）+ 标题「新建互动故事」。

### 3.2 主区
| 元素 | 定义 |
|---|---|
| 引导语 | 「想讲一个什么故事？」+ 一行副文案说明产物（脚本层草稿、生成后去向） |
| 创意输入框 | 页面主角：大文本框，自动聚焦，占位给示例句式；为空时生成按钮禁用 |
| 故事名称 | 可选；留空时按创意首行自动起名（前 12 字） |
| 生成按钮 | 主色；点击即进入生成态 |
| 清空 | 清空创意与名称（不清高级选项） |

### 3.3 高级选项（折叠区，默认收起）
折叠按钮为真按钮（aria-expanded，规范 §10）。区内三组，全部面向高级用户：

| 组 | 内容 |
|---|---|
| 结构公式 | 选择点数 / 每点选项数 / 结局数 三个下拉 + 随机公式按钮 + 输出格式规则说明（结局数 = 每点选项数） |
| AI 模板 | 一键生成提示文本（按公式自动选模板族）；模板下拉 + 打开 / 保存版本 / 删除模板 |
| 提示词预检 | 手工提示文本框 + 分析提示词（结构预检 + 一轮 AI 评审并返回优化版） |

纪律：三组只影响提示词装配，不改变产物语义；默认折叠 = 默认信任公式自动化。

### 3.4 生成态
表单替换为进度卡：脉冲点 + 「正在生成脚本草稿」+ 已过秒表 + 预期说明（本地模型约需 1–3 分钟，请勿关闭页面）+ **执行路径行**（12px 弱文色：`文本模型 provider / model · 经守护台资源调度` 或 `· 独立直连（租约已关）`，如实显示本次生成走的通道）+ **取消按钮**（中断请求，回表单且保留输入）。

### 3.5 结果态
- **成功**：绿点 + 「草稿已生成：标题」+ 主按钮「打开项目继续制作」（草稿确认毕业并进脚本工作室）+ 次按钮「返回首页」。
- **失败**：红字原因 + 「重试」（保留输入）+「返回」。**守护台离线专属引导**：失败原因为 `resource_scheduler_unreachable` 时，文案替换为「守护台离线且资源租约已启用。请启动守护台，或到 设置 → 守护台关联 关闭后重试」，并额外给「打开设置」直达按钮。

## 4. 状态机（逻辑图）

```chart flow

ok -> studio: 打开项目继续制作
ok -> home: 返回首页
```

## 5. 草稿联动规则

1. 生成中途放弃或待确认的故事进**草稿箱**（首页条目），不丢失。
2. 草稿箱「载入继续生成」：经预填通道（sessionStorage）跳到本页并回填创意/名称/公式；同名草稿存在时生成前给替换确认（删除旧稿并生成 / 取消）。
3. 「打开项目」= 草稿毕业：项目出现在项目库，草稿条目移除。

## 7. 代码结构（真相文件树，以仓内文件为准）

```text

  pages/CreateStoryPage.tsx    # 新建页：hero/主输入/高级折叠区/生成态/结果态
  hub/draftHistory.ts          # 草稿历史读写 + 预填通道（write/consume）
  studios/Hub.tsx              # 项目库（英雄卡跳本页；草稿条目经预填通道跳本页）

  App.tsx                      # stage 'create'（持久化恢复）

  routes/story.routes.js       # 创建与脚本生成端点族
```

实现映射：2026-10-20 已实施（弹窗 → 独立页）；Hub 由 2,112 行瘦身至 771 行。已知简化：旧弹窗的生成后富评审段（脚本预览/结构分析/AI 自检/继续修复）未随迁，生成后引导进工作室查看——如评审意见要求回补，属后续波次。

## 8. 自适应与文案

- 单列居中（max-width 720）；<1024 全宽内边距 16；输入框随内容增高。
- 全部文案中文用户语言；结构公式等技术内容只存在高级折叠区；样式取 `--ts-*` 语义令牌。
