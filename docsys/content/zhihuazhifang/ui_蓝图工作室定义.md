# 蓝图工作室定义（结构层 · 生产准备中心）

> 类型：**全局定义**——定义蓝图工作室的完整目标形态，超前于实现；实现状态只在 §10 实现映射登记。
> 上位契约：编辑器四区契约与"结构在蓝图、画面在合成"的分层不变。观感/文案/图标/分割线规则见《UI 设计规范》。

## 1. 定位

蓝图工作室 = **故事结构层 + 生产准备中心**。它回答四个问题：

1. 故事结构通不通？（编译与校验）
2. 这个故事需要哪些东西？（元素标记与缺口）
3. 这个故事看起来/读起来/听起来怎么样？（占位预演与配音）
4. 还差什么没准备好？（准备度）

**核心规则**：一切不依赖出图的准备工作都在蓝图层完成——合成层只负责补图、摆位精修与导出。出图是最贵的生产环节，所有能在出图前发现的问题必须在蓝图层暴露。

非目标：不做像素级编辑（合成层职责），不做文案精修（脚本层职责）。

## 2. 页面结构（组织图）


## 3. 顶栏定义

| 控件 | 定义 |
|---|---|
| 上一步：脚本 | 回脚本层（脏数据守卫） |
| 校验结论 | 结构校验结论（通过 / n 个问题） |
| 锁定事物 | 进合成层并自动打开锁定事物工作区（本层只提供入口与缺口上下文，锁定界面不变） |
| 准备度摘要 | 结构/元素/配音/图四段如实呈现（不阻断进入合成，禁止带病假装完整） |
| 保存 | 蓝图脏 ∪ 任一幕编排脏时可点；点击=保存蓝图文档+逐幕落盘编排草稿 |
| 下一步：进入合成 | 主按钮；悬停显示当前准备度摘要（还差什么） |

> 注记（2026-10-25 D1）：顶栏不设预演入口按钮——预演内嵌中栏第三视图（视图切换/步骤条动作进入）。

## 4. 能力定义（逐项）

### 4.1 结构编辑（基础能力）
节点图（结构图/卡片双视图）、分支增删改、编译校验（可达性/出度/结局闭环/id 规范——规则见《详细设计说明书》§3.1.3）。结构调整只在本层进行。

### 4.2 占位预演（previz，可交互——唯一演示形态）
- **是什么**：中栏第三视图（与卡片/结构图并列切换，**不是弹窗**）——无图可交互预演与编排：每幕 = 占位画框（代码绘制的带标签方块：背景满框/角色槽位/道具中部）+ 该幕文本 + 选择按钮组；选择即推进，可走完全部结局；**占位块可直接拖动编排**（改动进编排暂存置脏，点顶栏「保存」逐幕落盘该幕构图需求单草稿）。
- **行为**：画框比例随项目横竖模式（stageConfig）；摆位优先读 story.json 既有 placements 与本幕需求单草稿，否则确定性默认槽位；翻页/自动播放/选择交互三种推进方式；右栏属性面板联动（选中元素块即显示其位置/大小属性）；**点选回落纪律：点预演空白区或文本区即回场景属性**（场景属性永远一键可达，不许被元素属性困住）；编排改动不自动写盘（G 波"脏→保存"语义），保存后落盘不丢。
- **占位图预览（2026-11-01）**：元素已出图（主参考/已锁定姿势/状态变体）时，选中元素 → 右栏「预览图」点选候选，占位块即以真实透明图渲染（跟随拖动/缩放/翻转/纵深带）；显式选择写该幕构图需求单草稿 `imageAssetId`（`composition-draft` 端点收，摆位消费端按它优先选图）；「恢复默认选图」回到按姿态自动选图；「管理（出图）」深度回跳锁定事物向导第 5 步执行台（见 §4.7）。
- **作用**：一次操作同时验证五件事——文案通不通、分支对不对、构图密不密、元素齐不齐（未分析/未锁定的元素在占位块上如实标出）、**摆位合不合理（亲手编排即导演意图，强化后续锁定与出图判据）**。
- **规则**：预演是只读运行，不写任何真相源；占位布局是派生演示数据，真实摆位仍以合成层为准。
- **口径**：不设独立"文字试玩"——演示形态只有占位预演一种（2026-10-21 用户裁决）。

### 4.3 元素 AI 标记
- **是什么**：每个节点（场景）需要哪些角色/道具/背景，由 AI 从剧情文本提取并标记在节点卡上（元素徽标）；支持逐场景「AI 分析」补提取（写回 plan.json 同源，幂等更新），或要素库顶部「分析全部场景」对未分析幕串行批量提取（禁止并发；已分析幕按 analyzedAt 戳/assetIds 非空幂等跳过；任一失败即停并给出幕号/原因/引导，已分析幕保留可续跑；进度明面：按钮计数 + 步骤条逐幕递增 + 任务台账每幕一条）。
- **数据来源**：与资产计划（plan.json）同源——标记是计划的呈现，不另写第二份事实。
- **呈现**：节点卡上显示本幕元素徽标行；徽标带阶段状态点（已标记/已锁定/线稿/变体齐/已有图）。
- **缺口清单**：左栏要素库按"背景/角色/道具"聚合全部元素及其准备状态；缺口一目了然，点击徽标直达对应准备工作。

### 4.4 占位演示的定位
占位演示的能力已全部并入 §4.2 占位预演（唯一演示形态）；本节仅保留纪律注记：预演呈现的一切均为派生演示数据。

### 4.5 语音配音处置（声音区在场景属性内）
- **是什么**：每幕的台词/旁白在蓝图层完成配音准备：选中场景 → 右栏属性「声音」区 → 音色绑定 → 生成配音 → 试听；批量预生成在要素库/步骤条入口。
- **数据模型（2026-10-25 B 波落地）**：场景级配音记录落在资产计划——`plan.sceneVoices[sceneId] = { voiceId（音色库预设 id）、audioAssetUri（项目 assets/ai/voice/<sceneId>.<ext>）、durationMs（afinfo 实测，测不出为 null）、text、generatedAt、status }`；音频文件纳入压缩与导出链。
- **音色来源**：设置页语音卡的角色音色库（女声/男声/童声/长辈分组）；角色→音色的绑定在本层完成一次，全链复用。
- **批量生成**：走长任务台账（全局任务指示器可见进度、可感知失败原因）；未启用语音时动作阻断并给配置入口（《设置定义》阻断矩阵）。
- **下游复用**：同一条音轨供 H5 运行时播放与预演视频导出（V1）使用，不重复生成。

### 4.6 锁定前移
- **是什么**：蓝图层可直接进入锁定事物工作（按当前幕或全故事范围）。
- **规则**：锁定工作本身的界面不变；本层只提供入口与缺口上下文（哪些元素还没定长相）。

### 4.7 姿态需求定义与预演消费（当前真实能力，2026-10-27 K/R 波起在线；2026-11-01 定义/执行分工定型）
- **是什么**：角色元素的姿态需求（及道具元素的状态需求）在蓝图层完成**定义**：选中角色元素 → 右栏「姿态需求清单」逐条增删改（语义名新增，重名去重；逐条可改中文/英文提示词、可删）；每条需求带**视角/动作/表情组装器**、**配方库**应用、**AI 建议**（按需求关联剧情上下文生成中英双稿）与**翻译为英文**（走后端翻译链）。
- **分工（2026-11-01 裁决）**：需求定义只在蓝图（共享组件 `components/pose/PoseRequirementEditor`）；锁定事物向导第 5 步「出图管理」的场景姿态工作区**只执行**（选场景 → 需求只读摘要 → 生成候选 → AI 评分 → 锁定并应用），定义 UI 不再两处重复——两处共用同一组共享组件/Hook（`components/pose/`：`PoseRequirementEditor`/`ScenePoseWorkbench`/`usePoseRequirementOps`/`usePoseAiSuggest`/`usePromptTranslate`/`poseTypes`/`assetUrl`）。
- **AI 入口**：要素库顶部「提取剧情姿势需求」（AI 从剧情文本提取各角色姿态需求并写回清单）与「AI 补齐多态需求」（角色姿势+道具状态需求串行补齐，资源互斥纪律，逐项任务台账进度）。
- **数据来源**：与资产计划同源——清单落 `plan.assets[].poseRequirements`，经窄写口 `PUT /api/projects/:id/ai/story/assets/:assetId/pose-requirements` 即时落盘（真相源编辑，不入编排脏保存链）；步骤条「事物锁定」副计数=ref_required 角色中已定义姿态需求的占比（如「锁定 8/9 · 姿态需求 2/3」）。
- **预演消费**：预演块/元素属性中元素姿态/状态**可选**——已生成姿势/状态变体（有 stateKey）以下拉选用，未锁定时诚实显示「锁定后可选择姿态」；选择经编排草稿写回该幕构图需求单（stateKey），合成层摆位/出图按 stateKey 消费；**显式预览图选择**写 `imageAssetId`（见 §4.2）。
- **管理回跳（2026-11-01）**：右栏「管理（出图）」写 `talkscene.lockWorkspace.poseFocus` 载荷（projectId+assetId+sceneId+reqId）进合成层，锁定事物向导自动打开并聚焦该资产的场景姿态执行台（grid 模式开二级详情锚姿势变体区；steps 模式落第 5 步展开+滚动）；未保存编排先 confirm（离开蓝图=丢弃语义如实）。执行台「修改需求」反向回蓝图（关向导回蓝图层）。
- **边界**：本层只定义需求与做选择，**不出图**；变体的生成/评分/锁定在锁定事物向导第 5 步「出图管理」的场景姿态工作区执行。

## 5. 准备度模型（本层新增的核心概念）

每个节点有一份准备度，全故事有一份汇总：

| 维度 | 判据 |
|---|---|
| 结构 | 校验通过 |
| 元素 | 本幕所需元素全部已提取且已锁定 |
| 配音 | 本幕台词全部已生成配音（语音未启用时此维度记"跳过"） |
| 图 | 本幕场景图已绑定（出图环节，合成层完成） |

「进入合成」按钮呈现准备度摘要（如"元素 8/9 · 配音 0/6 · 图 0/6"）；准备度不阻断进入合成，但必须如实可见（禁止带病假装完整）。

## 8. 要素库定义（左栏）

要素库是**跨场景的资产准备清单**，按背景/角色/道具三族聚合：
- 标题行右侧三个批量动作：「分析全部场景」（对未分析幕串行逐幕 AI 提取；本地模型串行纪律，进度/失败/幂等语义见 §4.3）、「提取剧情姿势需求」（AI 从剧情提取各角色姿态需求清单并写回计划，见 §4.7）、「AI 补齐多态需求」（角色姿态+道具状态需求串行补齐，逐项任务台账进度）。提示词能力未启用时禁用并给设置引导。
- 多级管理：角色元素展开子级=姿态需求+姿势变体（按 stateKey 合并）、道具元素展开子级=状态需求+状态变体；子级黄点=新需求未生成变体。
- 每个元素：名称、所属场景数、准备状态点、操作（点击去锁定）；行内可改名（写计划真相源，即时落盘）。
- 续集与系列化：元素可来自资产继承（前作复用），继承来源有标注。
- 空态规则：未提取时显示"进入后先进行元素标记"引导一行，不显示空架子。
