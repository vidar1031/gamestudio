# 操作手册

> 面向：操作员/运维（生产管理员、接手运维的工程人员）。创作者请看《用户手册》。

## 1. 引言

### 1.1 编写目的
规定织话智坊各服务的安装、启停、监控、备份恢复与常见故障处置，保证系统可被独立运维。

### 1.2 背景
系统进程组：业务后端、编辑器、守护台后端、守护台前端、本地模型服务、出图服务、（按需）文档站点预览。

### 1.3 定义与参考资料
见《概要设计说明书》§5 运行设计、《运行时能力测试基准》（硬约束）。

### 1.4 参考资料
仓库 README、生命周期脚本目录、守护台仓同名脚本目录。

## 2. 软件概述

### 2.1 软件的结构
双仓：业务仓（talkscene：apps/server+apps/editor+packages+storage+docsys）+ 控制仓（local-agent-control：apps/control-server+apps/control-console）。

### 2.2 程序表
| 进程 | 启动方式 | 端口 | 日志/PID |
|---|---|---|---|
| 业务后端 | scripts/lifecycle/start_server.sh（仓根执行） | 1999 | .run/server.log/.pid |
| 编辑器 | scripts/lifecycle/start_project.sh（含后端） | 8868 | .run/editor.log/.pid |
| 守护台后端+前端 | local-agent-control/restart_control.sh | 2099/8870 | 控制仓 .run/ |
| 本地模型服务 | oMLX 应用（菜单栏） | 18888 | 应用日志 |
| 出图服务 | ComfyUI（Terminal 可见窗口启动，禁止静默后台） | 8188 | 终端输出 |
| 文档站点 | npm run docsys:build / docsys:serve | 8891 | 静态产物 |

### 2.3 文卷表
真相源 storage/projects/；全局配置 storage/_config/；控制面 state/；文档 docsys/content/ 与 docs/。

## 3. 安装与初始化
1. 双仓克隆并排安放（同级目录）。
2. 业务仓 `npm install`；控制仓按其 README 安装。
3. 复制 `.env.example` 为 `.env.local` 填密钥（不得入库）。
4. 安装并启动 oMLX 与 ComfyUI（ComfyUI 必须可见窗口启动）。
5. 四服务自检：业务/编辑器/控制/控制台健康检查全部 200。

## 4. 运行说明

### 4.1 运行表
| 运行（作业） | 前置 | 操作 | 结束判据 |
|---|---|---|---|
| 日常开机生产 | 3 完成 | 启业务+编辑器+守护台；确认模型在线 | 健康检查全绿+调度器 idle |
| 大批量出图 | 4.1 | 守护台发起正式会话；盯台账 | 台账 done 且无 error |
| 文档发布 | 无 | docsys:build 后拷 dist/ | 站点可开、链接通 |
| 日常关机 | 无 | 停守护台→停业务→按需停出图/模型 | 端口全释放 |

### 4.2 运行步骤（启停）
- 启动顺序：模型服务 → 出图（按需）→ 业务后端+编辑器 → 守护台双端。
- 停止顺序：守护台 → 业务面 → 出图/模型（按需保留）。
- 重启纪律：业务后端从仓根跑生命周期脚本（脚本有 cwd 校验）；控制面用其仓 restart_control.sh。

### 4.3 各运行（作业）说明
- 生产会话：守护台发起；观察任务队列与会话时间线；失败按提示处置（取消/恢复/重试）。
- 模型切换：经守护台模型切换接口（静默边界保护，占用时 409）。
- 内存墙处置（资源墙）：oMLX 应用整体重启 → 守护台装模型 → 重提任务；连续两轮失败停摆上报。

## 5. 非常规过程（应急/恢复/再启动）
- 进程崩溃：持久化任务随服务重启恢复；中断任务看台账 interrupted 标记（不当成功）。
- 数据恢复：项目目录创作缓冲 snapshots/ 取最近快照拷回项目根；评审记录为 JSONL 可直接核对。
- 端口占用：用状态脚本查 PID；残留 PID 文件先删再启。
- 出图服务卡死：先 /free 释放显存，无效则退出重启（下次出图会自动拉起）。

## 6. 备份与迁移
- 备份=复制项目目录与 storage/_config/；迁移=整目录拷到新机并外置存储根指向。
- 文档体系 docsys/ 整目录可拷走独立运行。

## 7. 远程操作
不支持远程运维（本地优先设计）；机构部署形态另行评估（自托管站点阶段）。
