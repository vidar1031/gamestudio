# 合成工作室定义（编辑器主界面）

> 类型：**全局定义**——定义完整目标产品的合成工作室（编辑器主界面），超前于实现状态。上位契约：编辑器四区契约（顶=全局、左=结构、中=画布、右=属性，右栏是唯一编辑入口；对象优先于数据、结构优先于视觉）；观感/文案/图标/分割线规则见《UI 设计规范》。
> 本页不做结构编辑（蓝图层职责），不做文本精修（脚本层职责）。

## 1. 定位

合成工作室 = **故事的导演台**：把蓝图结构变为可玩画面与演出——摆位、背景、文案排练、校验、导出。它是编辑器的主界面，创作者的大部分时间在这里度过。

## 3. 顶栏定义（三段式收纳）

| 控件 | 行为 | 可见条件 |
|---|---|---|
| 返回工作台 / 返回蓝图 | 保存守卫后导航（脏数据先落盘） | 常显 |
| 播放起点选择器 | 选择预览起点节点（不影响蓝图结构/导出） | 有故事时 |
| 当前项目名 | 只读标识 | 常显 |
| 校验徽标 | chip：绿点「校验通过」/ 红点「n 个问题」 | 常显 |
| 播放 | 重启运行时播放 | 有故事时可用 |
| 保存 | 主色；仅脏态可点 | 常显，无脏禁用 |
| 导出 ▾ | 菜单：导出预览 / 导出发布包（H5) | 项目模式可用 |
| 制作 ▾ | 菜单（带说明小字）：锁定事物 / 场景出图 / 场景图审核 / 素材目录 / 完整度核实 | 项目模式有故事时可用 |
| 全局设置 | 运行时全局设置面板 | 项目模式 |

纪律：制作类动作一律收进「制作」菜单，不直接平铺；菜单项说明文字 12px 弱文色第二行。

## 4. 画布工具条（双簇）

| 簇 | 内容 | 显示条件 |
|---|---|---|
| 常态簇 | 编辑/预览模式徽标（点击切换）、− / 缩放值 / ＋、适应窗口、平移、撤销 | 常显 |
| 选择簇 | 左右反转、上下反转、前移、后移、删除（前置分隔线，淡入） | 仅当选中摆放且处于编辑模式 |

## 5. 左栏（结构管理）

页签四枚：节点 / 角色 / 资源 / 素材。节点列表按剧情顺序排列（含选择点与结局），点击节点=画布与右栏联动定位。素材页签提供项目角色与已锁定资产，拖入画布即生成摆放。

## 6. 右栏（属性编辑，唯一编辑入口）

- 场景节点属性：名称、尺寸与背景（方向/常用尺寸/宽高/适配/背景资源）、对话内容、类型等分区折叠；分区标题下细分隔线（规范 §10）。
- 摆放属性：选中元素后显示——变换数值、翻转、层级、图片来源追溯、动作立绘入口、调试信息折叠。
- 提示纪律：流程性说明一律 dim 弱提示一行（12px），禁止黄色说教长文。

## 7. 画布能力（编排器）

像素级命中点选（透明穿透）、拖放、缩放（0.05–4 以画布中心为基准）、平移工具、翻转、层级调整、撤销（快照栈深 50，Ctrl/Cmd+Z）、编辑/预览双模（预览只读）。画布区自适应剩余空间。

## 8. 状态与反馈

- 保存：脏态 1.2s 防抖自动落盘 + 手动保存；乐观锁冲突给引导横幅。
- 外部更新横幅：检测到项目被他窗口/流程更新时提示刷新，「知道了」本会话不再提示。
- 长任务（出图/走查/导出）一律有台账进度，禁止黑盒同步等待。
- Toast 统一底部弱提示；错误给原因+下一步。

## 10. 自适应

- 最低工作宽度 1280（创作工具口径）：低于此允许横向滚动，不允许布局破碎。
- 画布区吃剩余空间；右栏 320 定档；左栏随内容。
- 全部样式取 `--ts-*` 语义令牌；图标/分割线/折叠控件遵守《UI 设计规范》§10。
