# 数据库设计说明书

> 范围：纯文件真相源存储的结构设计（无传统数据库）。逻辑/物理结构与字段字典。

## 1. 引言

### 1.1 编写目的
规定真相源文件的组织、字段含义与读写规则，使任何模块读写一致、任何接手人员可按文档直接解析项目目录。

### 1.2 背景
系统无服务端数据库：项目为自包含目录；全局配置与模板另有目录；控制面运行数据在其仓 state/ 下。

### 1.3 定义与参考资料
见《概要设计说明书》§6、《数据要求说明书》。

## 2. 外部设计

### 2.1 标识符和状态
- 项目目录：`storage/projects/<projectId>/`（STUDIO_STORAGE_ROOT 可外置）。
- 全局配置：`storage/_config/studio_settings.json`；共享库：`storage/_shared/`（姿势骨架库等）。
- 控制面运行数据：`local-agent-control/state/`（会话/队列/审计/调度器状态/事件）。

### 2.2 使用它的程序
业务后端（读写）、编辑器（经后端 API 读写）、控制面（经业务面 API 读、经审核代理写审核）、导出插件（读）。

### 2.3 约定
- JSON 写盘一律"读取-合并-原子写入（tmp+rename）"；JSONL 一律追加。
- 图像引用一律相对路径（assets/...），外链形式仅用于 HTTP 访问层。

### 2.4 专门指导
- 不得跨项目目录读写；不得直接改他人运行中的文件（经 API 或合并函数）。

### 2.5 支持软件
Node.js fs/promises；无额外依赖。

## 3. 结构设计

### 3.1 概念结构设计（实体—关系）

```text
项目 ProjectV1（project.json）
  story StoryV1（story.json）   # 故事结构与剧情
    nodes 节点                  # visuals / placements / backgroundAssetId
  plan PlanV1（plan.json）      # 资产计划
    assets 资产
      参考候选 / 主参考 / 线稿
      poseVariants 姿势变体
      stateVariants 状态变体
      stateRequirements 状态需求
    scenes 场景                 # composition 构图需求单
  reviews/*.jsonl               # 评审记录
  ai tasks                      # 长任务台账
```

### 3.2 逻辑结构设计（字段字典·核心字段）

**ProjectV1（project.json）**
| 字段 | 类型 | 说明 |
|---|---|---|
| id/name/schemaVersion | string | 项目标识与契约版本 |
| characters[] | object | 角色主档（imageAssetId、ai.referenceAssetId） |
| assets[] | object | 项目资产（id/kind/uri/source{type,prompt,provider,postprocess}） |
| _rev | number | 乐观锁版本号 |
| aiBackground.storyAssetPlan | object | 计划副本（写路径负责同步） |

**StoryV1（story.json）**
| 字段 | 说明 |
|---|---|
| startNodeId/nodes[] | 起始节点与节点集（id=sceneId） |
| nodes[].choices[] | 分支选择（指向目标节点） |
| nodes[].visuals.backgroundAssetId | 场景绑定背景 |
| nodes[].visuals.placements[] | 摆位：characterId|propAssetId、imageAssetId、transform{x,y,scale,rotationDeg,flipX}、zIndex、visible |

**PlanV1（story-assets/plan.json）**
| 字段 | 说明 |
|---|---|
| assets[].id/name/category/aliases | 资产标识（character/prop）与别名证据 |
| assets[].anchorPrompt/referencePromptEn/negativePrompt | 英文锚点与负向词 |
| assets[].primaryReferenceAssetUri/referenceStatus | 主参考与锁定状态机（missing/candidates/selected/locked） |
| assets[].lineartHintAssetUri/lineartFinalAssetUri/lineartStatus | 线稿链 |
| assets[].poseVariants[] | 姿势/载体变体：id、poseKey/stateKey、skillId、sceneId/sceneIds、projectAssetId/projectAssetUri、score/reason、createdAt |
| assets[].stateVariants[] | 道具状态变体：stateKey、composite（合成方式）、projectAssetId、score |
| assets[].stateRequirements[] | 状态需求：stateKey/label/description/evidence/sceneIds/relatedAssetIds |
| scenes[].sceneId/sceneIndex/composition.items[] | 构图需求单：subjectId/x/y/scale/zIndex/flipH/stateKey |

**StatesDoc（story-assets/states.json）**
| 字段 | 说明 |
|---|---|
| scenes[].states[] | assetId/stateKey/stateLabel/evidence/relatedAssetIds |

**评审记录（reviews/image_reviews.jsonl、scene_reviews.jsonl）**
phase（pre_generate/lock_confirm/scene_bind）、verdict（approve/reject）、score、issues、suggestions、decidedBy、manualOverride、createdAt。

**台账（/ai/tasks 视图）**
taskId/kind/stage/current/total/message/done/result{generated,errors}/error。

### 3.3 物理结构设计
- 图像：立绘/变体无损 WebP；场景 JPEG q90；候选 WebP q92；旧版 PNG 存量批压迁移。
- 目录分域：assets/ai/story_assets/<category>/<assetId>/<日期>/（锁定真相源）、assets/ai/characters/（派生变体）、assets/ai/story_scenes/（背景）。
- 原子写：tmp+rename；快照：creation-buffer/snapshots/ 轮转 20。

## 4. 运用设计

### 4.1 数据字典设计
字典即本文 §3.2；schema 字段新增必须同步更新本文与 packages/schema 类型；弃用字段标记保留一个版本周期。

### 4.2 安全保密设计
- 密钥仅 .env（不入库、不入日志、不入快照）；
- workspace 外路径拒绝；客户端 scope 授权；审核批准留 decidedBy 与审计。
