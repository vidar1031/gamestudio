# 2026-05-15 GameStudio 当日日志

## 上午：Control Console 触发规则任务拆解

用户请求：在 Control Console 使用说明中添加每种分类的所有触发规则，并添加失败处理。

### 分析结果 (CT-001 完成)

**已有基础设施**（backend 层）：
- `config/hermes/routing/request_classification_rules.json` — 12 条规则，每条含 ruleId, requestType, priority, detector, route
- `requestClassificationRules.js` — `matchesDetector()` 函数实现 12 种检测器（answer_only, write_or_invoke_review, story_workflow_execute, gamestudio_bootstrap_execute, contextual_plan_answer, 6 种 inspect/list 类型）
- `requestClassifier.js` — `classifyReasoningRequest()` 完成 type→route 映射
- 5 个路由类型（answer_only, plan_then_answer, inspect_then_answer, workflow_execute, write_or_invoke_review）在代码中已存在

**缺失部分**：
1. 无 GET /api/control/routing 端点 — 前端无法获取规则表
2. 触发规则描述只有内部 `reason` 字段，缺少用户可读的 `triggerRule` 字段
3. Control Console 前端无任何路由/分类信息展示页面
4. 无触发规则匹配失败（unmatched prompt 走 fallback）的用户可见处理
