# 狼来了内容质量闭环工作流

> 本文档描述 GameStudio 互动故事生产的完整内容质量闭环工作流，以"狼来了"故事为例。

## 目标

实现从故事创建到最终交付的完整生产闭环，确保每个环节的产物都经过验证，失败时可追溯、可修复。

## 完整生产链路

### 阶段 1：故事创建与配置

1. **创建故事项目**
   - 事件：`story.project.create_ai`
   - 输入：标题、故事简介、互动结构参数
   - 输出：项目 ID、scripts.json、blueprint.json
   - 验证：scripts.json 存在且 cards.length > 0

2. **写入生成配置**
   - 事件：`story.configure`
   - 输入：projectId、config（题材/风格/目标受众/输出语言）
   - 输出：project.json 更新
   - 验证：配置写入成功

### 阶段 2：内容生成

3. **生成 Story Bible**
   - 事件：`story.bible.generate`
   - 输入：projectId
   - 输出：角色/道具/地点设定集
   - 验证：Story Bible 存在且包含必要实体

4. **编译蓝图**
   - 事件：`story.blueprint.compile`
   - 输入：projectId
   - 输出：blueprint.json
   - 验证：blueprint.json 存在且 nodes.length > 0

5. **蓝图评审**
   - 事件：`story.blueprint.review`
   - 输入：projectId
   - 输出：评审结果（verdict/score/issues/repairPlan）
   - 验证：评审通过或修复计划存在

### 阶段 3：资产生成

6. **生成资产计划**
   - 事件：`story.asset.plan.generate`
   - 输入：projectId
   - 输出：资产计划（角色/道具/场景）
   - 验证：资产计划存在且包含必要资产

7. **生成锁定事物参考图**
   - 事件：`story.assets.reference.generate`
   - 输入：projectId、assetId、batchSize
   - 输出：候选参考图
   - 验证：参考图存在且质量合格

8. **锁定主参考**
   - 事件：`story.assets.reference.select`
   - 输入：projectId、assetId、assetPath
   - 输出：锁定参考图
   - 验证：参考图锁定成功

### 阶段 4：场景渲染

9. **批量渲染场景图**
   - 事件：`story.scene.render_batch`
   - 输入：projectId、onlyMissing
   - 输出：场景图
   - 验证：场景图存在且绑定到 story 节点

10. **生成立绘分层站位**
    - 事件：`story.scene.placements`
    - 输入：projectId
    - 输出：placements 数据
    - 验证：placements 存在且正确

### 阶段 5：校验与导出

11. **校验项目**
    - 事件：`story.project.validate`
    - 输入：projectId
    - 输出：validation 结果
    - 验证：validation.ok === true

12. **完整度核实**
    - 事件：`story.completeness.check`
    - 输入：projectId
    - 输出：完整度报告
    - 验证：所有场景、角色、道具完整

13. **导出项目**
    - 事件：`story.project.export`
    - 输入：projectId
    - 输出：builds/latest/dist
    - 验证：dist/index.html 存在

## 质量门禁

每个阶段都有质量门禁：
- **写入前审核**：所有写入操作必须人工审核
- **产物验证**：每个步骤执行后验证真实产物
- **失败回滚**：验证失败时自动回滚到之前版本
- **证据记录**：所有操作记录到证据包

## 失败处理

- **重试机制**：失败时自动重试（最多 3 次）
- **修复策略**：根据失败原因自动修正（如调整 prompt、增加 timeoutMs）
- **人工介入**：超过重试次数后，人工介入处理

## 证据链

每个生产任务都有完整的证据链：
- 输入参数
- 执行步骤
- 产物验证结果
- 审核记录
- 失败原因（如有）
