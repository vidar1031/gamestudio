# 任务单规范

每个自动化任务必须有独立任务单（一个任务一个 md 文件）。

## 1. 必填字段

- task_id: 全局唯一
- title: 任务标题
- source: 需求来源（用户/测试计划/巡检）
- objective: 任务目标
- scope_in: 范围内
- scope_out: 范围外
- constraints: 约束条件
- acceptance: 验收条件
- owner: 主负责人
- agents: 参与 Agent 列表
- deadline: 截止时间

## 2. 证据字段

- evidence_code: 代码变更证据
- evidence_test: 测试证据
- evidence_runtime: 运行证据
- evidence_risk: 风险与兜底

## 3. 状态字段

- status: queued | running | waiting_review | blocked | failed | passed | archived
- retry_count: 重试次数
- last_error: 最近错误摘要
- next_action: 下一步动作

## 4. 规则

- 无 task_id 不执行。
- 无 acceptance 不开始编码。
- 无 evidence 不允许 passed。
