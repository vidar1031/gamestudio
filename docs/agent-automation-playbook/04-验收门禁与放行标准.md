# 验收门禁与放行标准

## 1. 门禁分层

- G0 环境门禁：服务健康、依赖可达、配置完整。
- G1 路由门禁：请求分类正确、工作流命中正确、执行路径可追溯。
- G2 产物门禁：目标文件/接口/构建产物存在且有效。
- G3 质量门禁：测试通过、回归通过、风险可接受。

## 2. 放行条件（全部满足）

- 任务单 acceptance 全部满足。
- 关键测试全部通过。
- 证据字段完整。
- 无 P0/P1 未处理缺陷。

## 3. 阻断条件（任一命中）

- 缺少执行证据。
- 关键链路失败但被标记为 passed。
- 未经审核的写操作。
- 发现安全边界风险。

## 4. 输出模板

放行结论必须包含：
- verdict: PASS | FAIL | BLOCKED
- reason: 结论原因
- evidence: 证据索引
- residual_risk: 剩余风险
- follow_up: 后续动作
