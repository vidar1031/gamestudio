完整阶段、任务依赖、测试用例和最终验收定义见 `12-自动生产系统总实施与测试计划.md`。必须按阶段 0 至阶段 4 执行：

## 当前完成定义

不以“模型说完成”或单次 E2E 作为完成。最终放行前必须满足 `12` 的全部阶段门与最终生产验收。

1. cron 能触发至少一次真实 P0 生产。
2. 生产结果有 project、artifacts、日志、审核记录和最终 verdict。
3. 模型/服务异常时系统明确 `FAIL` 或 `BLOCKED`，不伪造成功。
4. 人可在守护台观察、取消、恢复或审核任务。
5. 所有写入与执行都经过治理层 API 和审核记录。
