# 角色与职责矩阵

## 1. 角色定义

- Orchestrator Agent（编排者）
- Executor Agent（执行者）
- Reviewer Agent（审核者）
- Quality Gate Agent（质量门禁）
- Recovery Agent（恢复与重试）
- Human Owner（人工负责人）

## 2. RACI 矩阵

| 事项 | Orchestrator | Executor | Reviewer | Quality Gate | Recovery | Human Owner |
| --- | --- | --- | --- | --- | --- | --- |
| 任务拆解与分派 | A/R | C | C | I | I | I |
| 代码与配置修改 | C | A/R | C | I | I | I |
| 测试执行与结果收集 | C | A/R | C | C | I | I |
| 放行判定 | I | C | C | A/R | I | C |
| 异常恢复 | C | C | I | I | A/R | C |
| 终审与业务背书 | I | I | C | C | I | A/R |

说明：
- R = Responsible（执行）
- A = Accountable（最终负责）
- C = Consulted（被咨询）
- I = Informed（被通知）

## 3. 模型分工建议

- 小模型：分类、抽取、格式化、规则检查。
- 中模型：计划生成、代码修改建议、测试分析。
- 大模型：复杂决策、跨模块排障、风险评估。

## 4. 冲突处理

- 冲突优先级：门禁规则 > 项目契约 > 执行建议。
- 两个 Agent 结论冲突时，由 Reviewer 发起复核；无法收敛则升级 Human Owner。
