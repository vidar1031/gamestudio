# 北极星目标

## 1. 最终目标

在最少人工介入下，实现“需求 -> 设计 -> 实现 -> 测试 -> 验收 -> 复盘”的稳定自动闭环。

## 2. 成功定义

- 可持续：系统可连续运行，任务不会因单点失败永久卡死。
- 可验证：每个结论都有证据（日志、文件、接口结果、测试记录）。
- 可恢复：任务中断后可从断点恢复，而不是总从头重跑。
- 可协作：不同 Agent 与模型对同一任务理解一致、动作一致、标准一致。

## 3. 量化指标（建议）

- 自动完成率 >= 85%
- 平均恢复时间（MTTR）<= 30 分钟
- 关键门禁误放行率 <= 1%
- 任务证据缺失率 <= 2%

## 4. 非目标

- 不追求一次性“全自动替代人工”。
- 不允许跳过审核与门禁换取速度。
- 不允许模型自由发明未注册动作。
