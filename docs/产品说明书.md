## 1. 产品概述

### 1.1 一句话定位

**用语言描述，生成分支式可交互故事；同一份生产，一键再导出为可发布推广的预演视频。**

本地优先（local-first）：全部生产算力在本机（27B 文本模型 + 本地视觉模型 + ComfyUI），零云依赖、零按次计费、素材不出机。

### 1.2 愿景

让"一个故事创意"到"可玩的交互故事 + 可传播的视频"的成本，从"一个团队数周"降到"一个人一杯茶"。

### 1.3 产品三形态（输出物）

| 形态 | 产物 | 用途 | 现状 |
|---|---|---|---|
| ① H5 交互故事 | 可玩网页包（分支选择、字幕、运镜，≤5MB） | 嵌入站点/公众号/课堂 | ✅ 已验证（多故事导出可玩） |
| ② 预演视频 | MP4（按确定路径播放全剧情，字幕+配音+运镜） | 抖音/B 站/视频号推广、客户过审演示 | 🔲 待建（本说明书 F5） |
| ③ 其它形式 | 考虑中：PDF 绘本序列图、GIF 预告、直播演示模式 | 备选 | 🔲 考虑中 |

### 1.4 发行形态（产品本身的打包）

| 形态 | 说明 | 阶段 |
|---|---|---|
| 桌面软件 | 双仓 + 本地模型依赖打包为一键安装的应用（macOS 先行） | β 阶段目标 |
| 自托管站点 | 服务端形态部署，多用户经浏览器使用（守护台即管理面） | 1.0 评估 |
| 开发套件 | 当前两仓源码形态（现状） | 现状 |

## 2. 市场与竞品

### 2.1 市场坐标

- **AI 视频短剧**（可灵/即梦/PixVerse 类）：已成熟，线性视频输出，按次/按量计费，云端。其短板＝无交互、无治理、素材上云、改动即重计费。
- **互动叙事工具**（视觉小说/分支绘本编辑器）：交互有但视觉靠人工绘制，无 AI 生产链。
- **演示工具**（PPT/Keynote）：自动化演示机制成熟（自动播放/演讲者视图/排练计时），但无内容生成。

### 2.2 差异化主张（本产品独占交集）

1. **交互 + 视频双输出**：一条生产链，交互故事与推广视频同源于场景/摆位/字幕数据（见 §4 F4/F5 同源性）。
2. **本地优先可治理生产**：每张图经审图门禁、每个动作留证据链——教育/出版/企业客户（B 端）的合规卖点。
3. **分支叙事结构**：AI 视频短剧是线性的；本产品天生多结局，视频形态可按任意剧情路径导出。

### 2.3 目标用户

| 用户 | 核心诉求 | 对应形态 |
|---|---|---|
| 绘本/儿童故事创作者 | 创意快速可视化、可玩样品 | ① |
| 自媒体/出版推广 | 各平台预演视频批量产出 | ② |
| 教育/企业培训 | 可审计的内容生产、离线可用 | ①+②+治理 |
| 演示/发布场合 | 无人值守自动演示 | ②+PPT 机制（F6） |

## 3. 产品能力总规格（功能分解）

> 每项含：定义 / 输入 / 输出 / 验收口径 / 现状。

### F1 语言描述→故事结构
- 定义：一句话创意 → 公式化脚本（2 选择点等结构公式）→ 故事圣经 → 资产计划。
- 验收：结构校验零 issue；圣经五要素齐全；资产场景归属完整。
- 现状：✅ 已验证（能力矩阵）。

### F2 视觉资产生产
- 定义：资产抽卡 → AI 评审 → 锁定 → 线稿 → 姿势/状态/载体变体 → 摆位上场。
- 验收：出图总账 100%；每个上场元素有锁定真相源；剧情状态变体按场景正确切换（多故事生产实测，证据见能力矩阵）。
- 现状：✅ 主干已验证（2026-10-18 状态变体链全通）。

### F3 交互编排
- 定义：分支选择点、场景编排器（拖放/缩放/层级/翻转）、动作立绘。
- 验收：编辑器四区契约；导出运行时逐位还原摆位。
- 现状：✅ 已验证（编排器探针实测）。

### F4 H5 交互故事导出
- 定义：引用收集 + 压缩（≤5MB）+ PixiJS 运行时打包。
- 验收：导出包无头实测零 console 错误、分支可推进。
- 现状：✅ 已验证。

### F5 预演视频导出（新建）
- 定义：选定剧情路径（或全结局矩阵）→ 按走查同款确定性播放 → 逐场景帧捕获 → 字幕/配音/运镜合成 MP4。
- 输入：项目 ID + 路径策略（主线/全结局/指定路径）+ 平台预设。
- 输出：MP4；平台预设：竖屏 1080×1920（抖音/视频号）、横屏 1920×1080（B 站/官网）、方形 1080×1080。
- 组成：① 播放引擎复用走查确定性路径枚举（storyWalkthrough.js 已具备）；② 帧捕获（PixiJS 离屏渲染/无头录屏）；③ 字幕轨（场景文本，已验证字幕式文本能力）；④ 配音轨（TTS——设置已有 doubao 通道，本地 TTS 为待建备选）；⑤ 合成（ffmpeg 管线，出图即压同族纪律）。
- 验收：样片三平台预设各一条；口型/字幕与场景停留时间一致；单场景时长可配；总文件 ≤50MB/分钟级。
- 阶段：P5 波次实施（见 §6 路线图）。

### F6 自动化演示机制（借鉴 PPT，新建）
- 定义：**场景即幻灯片**——演示模式把场景序列当幻灯片自动播放：自动翻页计时、演讲者注释（场景备注/讲解词）、排练计时、无人值守循环播放。
- 与 F5 的关系：**同一播放引擎**——演示模式是实时渲染版，视频导出是离线渲染版；演讲者注释即配音稿/字幕源。
- 验收：演示模式可全屏自动播放全故事；注释随场景切换；可一键"把本次演示录成视频"（=F5）。
- 现状：🔲 待建（与 F5 同波次）。

### F7 审图与质量闭环（强化）
- 定义：统一审图通道（在线 Kimi/本地视觉模型），无在线模型时**强制本地审图不得跳过**；场景级与变体级评审→打回→复审闭环。
- 验收：登记链 fail-closed（无有效评审分不放行）；评审记录全落 reviews/；编辑器设置有统一审图通道 UI。
- 现状：⚠️ 方案已盘点待批准（2026-10-19 待决策项）。

### F8 生产治理（守护台）
- 定义：正式生产工作流、三级图片审核门禁、托管审批、资源互斥调度、失败即停+策略表重驱、全程证据链。
- 现状：✅ V1.0 看门狗自治已达成；V1.1 资源自愈建设中。

### F9 可打包性（新建，发行前置）
- 定义：依赖清单固化（模型/ComfyUI/ffmpeg）、一键安装器、首次运行自检向导、离线许可。
- 验收：干净 macOS 机器一键安装到可生产；无网络环境可运行（模型预置）。
- 现状：🔲 待建（β 阶段）。

## 4. 关键架构决策（产品级）

1. **双形态同源**：H5 与视频共享 story.json/placements/字幕数据与同一渲染运行时——任何一处的画面修复两形态同时受益。禁止为视频另起渲染旁路。
2. **控制面/业务面分离保持**：守护台管治理与编排，业务仓管生产与交互；发行时两进程可打包为单应用双服务。
3. **PPT 机制即视频引擎**：自动演示（实时）与视频导出（离线）共用播放引擎，避免双实现漂移。
4. **本地优先不妥协**：任何云能力（Kimi 评审/豆包 TTS）必须有本地兜底路径（本地视觉/TTS），无网可生产（见 F7/F9）。
5. **改名不动真相源**：品牌名、包名、UI 文案可换；API 路径、存储结构、schema 契约、事件名不动。
