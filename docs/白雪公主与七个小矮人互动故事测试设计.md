# 《白雪公主与七个小矮人》互动故事测试设计

> 用途：TalkScene 多角色、分支、服饰状态与构图覆盖的结构测试样本，不是已生产或已审核的成品故事。
> 目标年龄：建议 8+；画面方向：明亮、非恐怖的童话绘本。女王的威胁通过伪装、苹果和角色反应表达，不展示伤害细节。
> 场景数：15 个（含 2 个结局）；互动点：森林路线二选一、苹果应对二选一、结局二选一。

## 故事梗概

白雪公主离开王宫后，在森林中选择一条路线，来到七个小矮人的小屋。女王变装成苹果商贩试探她。白雪公主可以接下苹果，也可以先询问并向矮人求助；两条路径都会让她识破女王的计划。最后，她可以选择公开揭穿女王、让王国恢复公正，也可以要求女王停止追逐并选择离开王宫，自己建立新的生活。选择会改变路径和结局，两个结局均尊重白雪公主的主动决定。

## 分支与验收关注点

- 有 15 个 `scene`/`ending` 节点；`sw-02`、`sw-07`、`sw-13` 是三个真实选择点；所有选择边指向存在节点。
- 两个起始路线在 `sw-05` 合流，此节点只写两条路线都成立的事实，不提独占路线道具。
- 接苹果路线经 `sw-08 → sw-10`；拒绝路线经 `sw-09 → sw-11`；两条路径在女王身份揭示前都恢复到“白雪公主清醒、知道商贩有问题”的共同事实，再进入 `sw-12`。
- 结局分支分别可达 `sw-14` 与 `sw-15`；每个结局只总结本路径共同发生的事件，不提另一结局选择。
- 所有场景需对账角色、道具与状态变体；七矮人群像场景必须有 7 个独立矮人角色项，各项有不同 `x`/`zIndex`，并能选到各自允许的状态。
- 此结构样本不验证图像模型能否稳定画出 9 人构图、女王身份连续性或人物审美质量；这些仍需正式生产、候选图盲评和人工审核。

## 模拟边界

本次模拟使用仓库服务端 `buildCompositionInput` 与 `validateCompositionCoverage` 对隔离夹具做结构检查，不创建 `storage/projects` 项目，不请求模型，不生成或导出图片。它验证当前工具的场景/角色/道具覆盖合同，不等价于完整 TalkScene UI 操作或视觉质量验收。
